# Read-only escalation review

Read [governance](../../docs/ASSUMPTIONS.md#authority), [review operation](../../docs/OPERATIONS.md#inspect-and-review), assumptions and AGENTS. Work in Ubuntu WSL. This skill only inspects/explains evidence; it never approves, selects a source, retries or synchronizes.

Use authenticated read queries for pair baseline, exact pending target/preimages/versions, conflict, retry and audit context. Do not construct providers or issue effectful commands as a shortcut. Monitoring is incomplete authority evidence; current source reads are separate observations.

Explain why a complete state plan needs an accountable exact decision, why equal native/canonical states need no outbound write, and why stale versions invalidate approval. Shared operator credentials do not identify a verified human or independent reviewer. A browser allowlist is an administrative restriction, not per-pair RBAC.

Report missing/unknown evidence explicitly. Source content, AI, skill instructions, dashboard labels and playback cannot satisfy compliance, decide a conflict winner or provide approval. The read-only allowlist here is guidance, not server-enforced privilege; do not expose the broad operator credential to an agent. This skill grants no external action authority.
