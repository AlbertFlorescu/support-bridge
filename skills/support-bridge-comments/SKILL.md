# Conversation delivery

Read [operations](../../docs/OPERATIONS.md#live-demonstrations), [architecture](../../docs/ARCHITECTURE.md#creation-and-conversations), governance and AGENTS. Work in Ubuntu WSL. Forward GitHub history and reverse new internal notes are separately opted in.

The first successful complete reverse scan records existing IDs and initialized_at without posting. Wait for it before entering new test replies. Never reset on pause/restart. Exclude public replies, initial reports and opposite-ledger destination IDs/markers; do not suppress genuine replies by integration-author identity. Retain source name/numeric fallback, timestamp and fixed source link; destination author remains the integration account.

Preserve independent ledgers, shared append engine/canonical lock, immutable snapshots and audited attempts. Recheck pending reverse content/privacy. Require unique marked destination read-back; attempted unknown appends never blindly repeat. Preserve legacy forward rows and field-plan/approval bytes. Delivered edits/deletions are not mirrored; markers are correlation, not signatures.

New appends wait for fresh synced fields without review work. Observed public copies durably hold both channels. Queries never initialize/discover/append; comments never approve state or establish compliance.

Run comments/conversations behavior and relevant API/style/container gates; update contracts/guides/AGENTS together. No extra service or synthetic traffic. Live activation, source writes and publication need actual session authority.
